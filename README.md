# 🔵 The Blue Notebook

> Learning cybersecurity from zero, one page at a time.

Welcome to The Blue Notebook.

This is my public cybersecurity learning journey. I'm starting from the basics and documenting what I learn along the way — networking, Linux, security fundamentals, SOC, SIEM, labs, investigations and more.

I'm not here to pretend I'm an expert.

I'm learning, practicing, making mistakes, fixing them, and writing everything down so I can actually remember it. If you're also starting cybersecurity, feel free to learn along with me.

## 🧪 How I learn

**Learn → Understand → Practice → Document → Share**

I document the things I actually learn and practice. Some pages may start simple, contain mistakes, or change as my understanding improves.

The goal is not to make everything look perfect. The goal is to build a useful record of the journey.
